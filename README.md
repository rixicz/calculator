# Calculator

A simple JavaScript calculator project built as part of The Odin Project.

## Live Demo

Try it live: https://rixicz.github.io/calculator/

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, division
- Clear (`C`) button to reset the calculator
- Display limit of 13 digits
- Responsive button layout with hover feedback

## Files

- `index.html` — calculator markup
- `style.css` — calculator styling
- `script.js` — calculator logic and event handling

## Usage

1. Open `index.html` in your browser.
2. Use the numeric buttons to enter values.
3. Use the operator buttons to perform calculations.
4. Press `=` to evaluate the expression.
5. Press `C` to clear the calculator.

## Notes

- The calculator works with integer input values.
- Division by zero returns a friendly message.
- The display is limited to 13 characters to keep the layout stable.
